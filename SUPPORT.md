# Support

## How to Get Help

Please use the appropriate channel for your request:

- **Bug report**: Open an issue using the bug template.
- **Feature request**: Open an issue using the feature/request template.
- **Question / Discussion**: Use Discussions (if enabled) or open an issue.
- **Security issue**: Report privately by following `SECURITY.md`.

## Before Opening a Request

Please check the following first:

- Read `README.md`, `CONTRIBUTING.md`, and existing issues.
- Confirm the issue still occurs on the latest version.
- Prepare minimal reproducible steps.

## Support Policy

- We cannot guarantee immediate responses for all requests.
- We may ask for additional details if the report is not reproducible.
- Community-based support and collaboration are welcome.
